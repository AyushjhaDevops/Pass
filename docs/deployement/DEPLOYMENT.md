# Deployment Guide

## Password Security Toolkit

The Password Security Toolkit is a client-side password security application.

The application is designed to run without a backend and performs password generation,
analysis, passphrase generation, PIN generation, and privacy-related processing locally
in the browser.

---

## Requirements

- Node.js
- npm
- Modern web browser
- HTTPS in production
